Sou estudante de **Engenharia de Software** e **Cibersegurança** (Estácio) e construo APIs REST em **Python e FastAPI** aplicando segurança desde o design (**OWASP**). ## 🧭 Como eu trabalho

- **Segurança desde o design:** penso em como a aplicação pode falhar ou ser abusada antes de escrever o código.
- **Testado:** casos positivos e negativos com pytest, para reduzir falsos positivos e regressões.
- **Modular:** separação entre camada HTTP, regras de negócio, segurança e acesso a dados.
- **Documentado:** decisões de segurança e trade-offs explicados no README de cada projeto.

**📚 Estudando agora:** CI/CD · arquitetura de software · ciência de dados
